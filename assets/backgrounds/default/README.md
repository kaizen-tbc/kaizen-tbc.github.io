# Default encounter backgrounds

44 default arena/encounter background images, one per TBC Classic raid boss (all 7
raids), named `<raid-code>-<boss-slug>.jpg` using the same short codes as
`RAID_SHORT_CODES` in kaizen_raid_manager.html (kara, gruul-mag, ssc, tk, hyjal, bt, swp).

These are meant as a starting point for a new strat's background image - "Replace
Image" stays available in the Strat Manager for anyone who wants a custom
screenshot instead.

## Notes
- `kara-opera.jpg` covers all three Opera Event variants (Big Bad Wolf, Romulo and
  Julianne, Wizard of Oz) - they share one stage.
- `hyjal-winterchill.jpg`/`hyjal-anetheron.jpg` are identical (both fights happen at
  the Alliance base); `hyjal-kazrogal.jpg`/`hyjal-azgalor.jpg` are identical too
  (both at the Horde base).
- Sourced as reference screenshots for personal/guild-internal use, not redistributed
  as a public asset library.
